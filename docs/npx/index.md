# snnForge

**Hardware-Aware SNN Training**

snnForge trains spiking neural networks with [snnTorch](https://snntorch.readthedocs.io), taking the target neuromorphic hardware into account, so that the trained networks run on the SoCs generated by [RVX](../rvx.md).
