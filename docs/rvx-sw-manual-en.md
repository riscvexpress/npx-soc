# NPX Software Development Manual

## Overview

- This manual is intended for developing software for SoCs using NPX.

- All software must be developed with this constraint in mind to ensure correct functionality since the NPX SoC is designed as a lightweight platform and therefore does not support a general-purpose operating system.
