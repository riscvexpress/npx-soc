# NPX

**Neuromorphic Processor eXpress**

NPX is an integrated framework for developing lightweight neuromorphic SoCs, from spike-based learning to FPGA prototyping.

<p class="rvx-funding">Under development by <a href="https://etri.re.kr/eng/main/main.etri"><strong>ETRI</strong></a>, South Korea, with support from the IITP grant (No. RS-2025-02263706), funded by MSIT.</p>

## Key Features

- Compatible with both Linux and Windows
- Free for non-commercial research use with citation
- Integrated framework for learning and hardware
- Extensible with AMBA-compliant IP blocks
- NeuGEMM accelerator for efficient GEMM and Conv2D operations
